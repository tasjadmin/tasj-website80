# User Testing Plan — TASJ Redesigned UI

## Objectives
- Validate improved visual hierarchy, clarity, and engagement
- Ensure zero workflow disruption across event registration and payments
- Confirm accessibility compliance (WCAG 2.1 AA) and performance

## Participants
- 8–12 users across:
  - Prospective attendees (non-members)
  - Members
  - Admins (event organizers)

## Scenarios & Tasks
- Browse events, open details, register (member/non-member), proceed to payment
- Choose Pay Online, complete card form; choose Pay Offline and submit details
- Admin: filter registrations by method/membership; approve offline

## Success Metrics
- Task completion rate ≥ 95%
- Time-to-task (baseline vs redesigned) improved or unchanged
- Errors observed ≤ 5% of sessions; zero blockers
- SUS score ≥ 80; satisfaction surveys ≥ 4/5

## Accessibility Checks
- Keyboard-only navigation
- Screen reader (NVDA/VoiceOver) basic flows
- Contrast verification; focus-visible across interactive elements
- Reduced-motion preference respected

## Devices & Browsers
- Desktop: Chrome, Safari, Firefox, Edge
- Mobile: iOS Safari, Android Chrome
- Tablets: iPadOS Safari, Android tablet Chrome

## Instrumentation
- Lighthouse performance and accessibility scores
- Web analytics for click-through and drop-off
- Error logging (frontend) for UI issues on key flows

## Procedure
- Pilot with 2 users; refine prompts
- Main sessions with 6–10 users; moderated remote testing
- Post-session survey and debrief

## Reporting
- Findings summary
- Prioritized issues list (severity, effort)
- Iteration backlog and timeline
