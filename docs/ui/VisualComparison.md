# Visual Comparison — Before vs After

## Hierarchy & Readability
- Before: headings and body sometimes close in contrast and scale
- After: defined type scale; larger headings; increased line-height for body; tightened letter-spacing for headings

## Color & Contrast
- Before: gold and orange occasionally used for text with low contrast
- After: deep navy for text; saffron for accents only; ensured AA contrast ratios for text

## Cards & Components
- Before: inconsistent padding/shadows between sections
- After: unified card styles (radius, border, shadow); consistent spacing tokens; hover affordances

## Motion & Feedback
- Before: limited interactive feedback
- After: subtle transitions; hover shadows; active filter chips; accessible focus rings

## Navigation & Footer
- Before: static bars with minimal affordances
- After: sticky translucent gradient nav; improved mobile menu; refined footer layout with accessible links

## Admin Tables
- Before: plain table visuals
- After: filter chips; readable columns; “Approve” actions; enriched payment method/status visibility

## Accessibility
- Before: focus/contrast improvements needed in places
- After: universal focus-visible styling; color contrast checks; keyboard navigability confirmed
