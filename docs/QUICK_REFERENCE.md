## 🎯 Common Tasks

### Adding a New Feature
1. Implement the feature in `src/`
2. Create documentation in `docs/features/`
3. Update `docs/README.md` index

### Updating Mobile Styles
1. Review [Mobile UX Guide](mobile/MOBILE_UX_IMPROVEMENTS.md)
2. Apply changes to CSS files
3. Update [Mobile Summary](mobile/MOBILE_RESPONSIVE_SUMMARY.md)

### Configuring Payment
1. Follow [Payment Quick Start](payment/PAYMENT_QUICK_START.md)
2. Set up [Stripe](setup/STRIPE_QUICK_SETUP.md)
3. Configure admin UI per [Admin Guide](payment/ADMIN_UI_PAYMENT_LINKS_GUIDE.md)

### Deploying to Production
1. Review [Netlify Setup](setup/NETLIFY_SETUP.md)
2. Check environment variables
3. Run build and deploy
